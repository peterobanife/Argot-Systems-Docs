# Argot Systems — Engineering Roadmap

Argot Systems develops innovative hardware platforms focused on oral‑health sensing (SmartBite) and modular interactive systems (AURORAE).

This roadmap outlines the development trajectory across both product lines.

---

## Phase 1 — Foundation (Now → 2 Months)
- Complete documentation for both projects  
- Build SmartBite V0  
- Build AURORAE Concept Prototype  
- Establish GitHub repos + structure  
- Begin firmware architecture  

---

## Phase 2 — Prototype Development (2 → 6 Months)
### SmartBite
- Build V1 prototype  
- Improve ergonomics  
- Add app integration  
- Validate calibration accuracy  

### AURORAE
- Build V0 multi‑board prototype  
- Implement communication protocol  
- Improve lighting + sensor integration  

---

## Phase 3 — System Integration (6 → 12 Months)
### SmartBite
- Production‑ready enclosure  
- Advanced analytics  
- Multi‑sensor exploration  

### AURORAE
- V1 modular system  
- Advanced interactions  
- App integration  
- Production enclosure  

---

## Phase 4 — Pre‑Production (12+ Months)
- Manufacturing exploration  
- Supply chain research  
- Certification planning  
- Pilot testing
